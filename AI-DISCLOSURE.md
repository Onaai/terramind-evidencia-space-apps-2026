# Declaración de asistencia de IA y antecedentes

La implementación de TerraMind Evidencia fue asistida por OpenAI Codex en código de interfaz, estilos, motor estadístico, script de acceso a datos, pruebas, documentación y redacción. Las decisiones se documentan para revisión del equipo. No hubo validación por investigadores de NASA ni participación institucional de NASA en el desarrollo.

Los datos de `out/data/pilot.json` proceden de consultas registradas a NASA ORNL DAAC; no se generaron con IA. Las pruebas automatizadas contienen datos de control sintéticos, confinados a `tests-evidence/`; no alimentan la app.

La nueva interfaz `out/` usa una marca vectorial original construida en código y fondos cartográficos externos atribuidos. No contiene ilustraciones generadas por IA presentadas como imágenes de observación. El prototipo previo tenía una ilustración conceptual generada, identificada como tal; no se importa en esta versión.

El antecedente demostrativo se desarrolló antes del comienzo del evento. La implementación nueva empezó el 14 de noviembre de 2026, después de las 09:00 de Buenos Aires, y conserva el historial del repositorio. Deben declararse tanto los antecedentes como esta asistencia. No se presupone que reescribir código subsane una restricción temporal del concurso.

La declaración es información para que el equipo complete la presentación oficial con exactitud; no constituye un envío al evento ni autorización de sus organizadores.
